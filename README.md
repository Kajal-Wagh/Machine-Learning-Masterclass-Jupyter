This repository contains a comprehensive collection of Jupyter Notebooks covering foundational to advanced **Machine Learning** algorithms, data preprocessing techniques, feature engineering, and model evaluation methods implemented in Python using libraries like Scikit-Learn, Pandas, NumPy, Seaborn, and Matplotlib.

## 🔍 Overview
This project serves as a complete hands-on guide for understanding machine learning workflows. It covers everything from handling missing values and data encoding to building supervised/unsupervised models, tuning hyperparameters, and applying dimensionality reduction.

---

## 🛠️ Key Topics Covered

### 1. Data Preprocessing & Exploratory Data Analysis (EDA)
* Handling missing values (Imputation using Mean, Mode, Forward/Backward fill)
* Data Cleaning and Inspection (`isnull`, `describe`, `info`)
* Data Visualization & Correlation Heatmaps using Seaborn and Matplotlib

### 2. Feature Engineering & Encoding
* **Encoding Categorical Data:** One-Hot Encoding, Label Encoding, and Ordinal Encoding
* **Feature Scaling:** Standardization (`StandardScaler`) and Normalization
* Handling Outliers (Z-score and IQR-based filtering)

### 3. Supervised Learning
* **Regression:** Simple Linear Regression, Multiple Linear Regression, Polynomial Regression, and Regularization (Lasso & Ridge)
* **Classification:** 
  * Logistic Regression
  * K-Nearest Neighbors (KNN)
  * Naive Bayes (Gaussian, Multinomial)
  * Decision Trees & Pruning
  * Support Vector Machines (SVM)

### 4. Unsupervised Learning
* **Clustering:** K-Means Clustering, Hierarchical Clustering, and DBSCAN

### 5. Advanced Techniques & Ensembles
* Cross-Validation and Train-Test Splitting strategies
* **Ensemble Learning:** Bagging, Random Forest, AdaBoost, Gradient Boosting, XGBoost, Voting Classifier, and Stacking Classifier
* **Dimensionality Reduction:** Principal Component Analysis (PCA)
